# POST

POST

## Usage

``` r
tuber_POST(path, query, body = "", ...)
```

## Arguments

- path:

  path to specific API request URL

- query:

  query list

- body:

  passing image through body

- ...:

  Additional arguments passed to
  [`POST`](https://httr.r-lib.org/reference/POST.html).

## Value

list
